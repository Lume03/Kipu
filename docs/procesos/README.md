# Flujos funcionales

Los flujos de uso se mantienen en las historias y sus escenarios de aceptación, no en una segunda colección de instrucciones BPMN. Los 32 documentos `KipuApp/Procesos` contienen participantes, puertas de enlace e instrucciones para dibujar; permanecen con la entrega del curso, junto con Bizagi. No se importan diagramas ni se crean carpetas P01–P32 vacías.
